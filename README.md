# 🏦 Bank Loan Analysis Dashboard

## 📌 Project Overview
The Bank Loan Analysis project focuses on analyzing bank loan application data to understand lending activities, loan performance, and borrower behavior.

An interactive Power BI dashboard was developed to monitor key loan metrics, identify trends, and generate meaningful business insights to support data-driven decision-making.

## 🎯 Project Objectives
- Analyze overall bank loan applications.
- Understand loan approval and funding trends.
- Identify Good Loans and Bad Loans.
- Analyze loan amounts and repayment performance.
- Evaluate interest rates and Debt-to-Income (DTI) ratios.
- Track monthly loan application trends.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **CSV** – Dataset format.

## ⚙️ Implementation

1. **Data Import:** Imported the financial loan dataset into Power BI.

2. **Data Cleaning:** Used Power Query to clean and transform the dataset by handling data types and preparing data for analysis.

3. **Data Modeling:** Organized the data and created calculated measures using DAX.

4. **KPI Development:** Created KPIs such as Total Loan Applications, Total Funded Amount, Total Amount Received, Average Interest Rate, and Average DTI.

5. **Dashboard Development:** Designed interactive Summary, Overview, and Details dashboards using charts, graphs, cards, and slicers.

6. **Data Analysis:** Analyzed loan trends, loan status, borrower information, and lending performance to generate meaningful insights.

## 📊 Key Performance Indicators (KPIs)
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income (DTI) Ratio
- Good Loan Applications
- Bad Loan Applications

## 📈 Dashboard Features

### 1. Summary Dashboard
- Overview of total loan applications.
- Total funded amount and amount received.
- Good Loan vs. Bad Loan analysis.
- Loan status distribution.
- Key financial performance indicators.

### 2. Overview Dashboard
- Monthly loan application trends.
- Regional loan distribution.
- Loan term analysis.
- Employee length analysis.
- Loan purpose analysis.
- Home ownership analysis.

### 3. Details Dashboard
- Detailed loan application information.
- Loan status and borrower-related metrics.
- Interactive data exploration.

## 🔍 Key Insights
The dashboard helps identify:
- Trends in loan applications over time.
- Distribution of loans across different categories.
- Differences between Good Loans and Bad Loans.
- Relationship between loan amounts and borrower financial indicators.
- Overall lending performance.
